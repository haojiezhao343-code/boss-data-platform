## 平台使用类

**Q1：这个平台能做什么？**
A：BOSS数智平台提供三大能力：①文档导入——设备手册等文档经审查合规后自动解析入库；②知识问答——基于知识库智能问答；③智能问数——自然语言查询业务数据。

**Q2：上传的文档为什么被拒绝了？**
A：文档上传需通过三道审查：规则审查（敏感词/重复/空文件）、LLM 语义审查（敏感信息/违规内容）、人工审核（中风险文档）。被拒绝时页面会显示具体原因，常见原因有：命中敏感词、与已导入文档重复、文件为空或过大（上限 50MB）。

**Q3：文档显示"待人工审核"怎么办？**
A：说明审查智能体判定文档存在可疑内容（中风险）。管理员在"审核管理页"（/review.html）查看审查发现后可选择"通过并导入"或"驳回"，通过后系统自动继续导入。

## 设备配置类

**Q4：H3C 路由器如何配置 NAT？**
A：H3C 企业级路由器（如 ER2100、MSR 系列）配置 NAT 的一般步骤：登录 Web 管理界面 → 进入"高级设置 → NAT 设置"→ 选择地址转换方式（如 Easy IP 或地址池方式）→ 关联出接口 → 保存配置。具体命令行配置（NAT outbound / NAT server）请参考对应型号的用户手册。

**Q5：设备手册里"整本手册"和"配置指导"有什么区别？**
A：整本手册通常包含硬件安装、快速配置、命令参考、故障处理等全部内容；配置指导（如 Web配置指导）聚焦某一配置界面的详细操作说明，内容更深但覆盖面窄。

**Q6：MSR 系列路由器支持哪些 WAN 接口类型？**
A：H3C MSR 系列多业务路由器支持以太网（FE/GE）、ADSL/VDSL、E1/T1、3G/4G 等多种 WAN 接口，具体因子卡型号而异，详见《MSR系列开放多业务路由器》硬件手册的接口模块章节。

**Q7：无线网关 LA2608 的默认管理地址是什么？**
A：H3C LA 系列室内无线网关默认管理地址通常为 192.168.0.1（管理 VLAN 接口），默认账号密码见设备铭牌或快速入门卡片。首次登录后建议立即修改默认口令。

**Q8：如何排查路由器无法上网的问题？**
A：建议按以下顺序排查：①查看 WAN 口状态是否获取到 IP；②检查 NAT/拨号配置；③ping 上联网关测试链路；④查看路由表默认路由是否存在；⑤检查 ACL/防火墙规则是否拦截。详细故障处理流程参考对应型号手册的"故障处理"章节。

## 数据问数类

**Q9：智能问数支持哪些问法？**
A：支持自然语言统计查询，例如："统计2025年华北地区销售总额"、"对比各产品线季度销量"、"上月华东区订单数"。问数智能体会将其转换为 SQL 在数据仓库执行（仅允许只读查询）。

**Q10：问数功能生成的 SQL 安全吗？**
A：安全。所有 SQL 执行前经过审查器强制检查：仅允许 SELECT/WITH 等只读语句，INSERT/UPDATE/DELETE/DROP 等一律拦截，禁止访问系统库，且自动追加 LIMIT 防止大结果集。每次审查均留有审计日志。
