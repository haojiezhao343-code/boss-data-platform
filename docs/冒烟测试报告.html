六、遗留事项

  • 低test2 导入任务因多次服务重启丢失内存态，重新上传即可（功能本身已由 test1 实证）。
  • 低review 审计日志的内存统计在重启后清零，JSONL 文件仍在，后续可加启动时回载。
  • 建议node_md_img 图片摘要是串行调用（66 张图约 20-40 分钟），后续可加线程池并发。
  • 环境本地到 SiliconFlow 的网络偶发抖动（openai 客户端自动重试），已有降级兜底承接。

七、结论

多智能体架构（智库为主、问数与审查为辅）核心链路全部跑通：上传 → 规则审查 → LLM 语义审查 → （必要时）人工审核 → 智库导入（MinerU/多模态摘要/BGE/Milvus）→ 问数分析意图 → RAG/FAQ/兜底回答。人工审核闭环与多层兜底策略按设计工作。
